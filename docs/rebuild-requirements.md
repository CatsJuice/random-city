# 城市罗盘重建验收要求

## 产品目标

React + Three.js 的可观赏、可重生成的真实 3D 微缩城市。参考用户提供的城市旅游地图的层次、密度和细节，以及 Townscaper 的连贯建筑与自然光感。没有自由建造要求。不宣称复刻 Townscaper 的私有算法，也不把 wasm 字符串当作算法实现证据。

## 必须满足

1. 正方形实体底座；鼠标旋转、右键平移、滚轮缩放，触屏单指旋转、双指平移缩放；提供平移模式和复位。
2. 可复现的随机种子，必须改变地理结构，而不只是固定模板内的摆放：海岸方向与有无、河流走势与交汇、湖泊与岛屿、山峰数量及位置、街区规模和连接关系均可变化。
3. 一份世界数据驱动地形、水系、路网、桥梁、地块、静态物体和运动路径。
4. 水系和陆地共用距离场；河流可入海、流经内陆或交汇，湖泊可没有海岸，岛屿可以被海水包围；山地是连续地形，不固定在后方。
5. 道路为连通图，包含交叉口、人行道、车道线、斑马线、路灯、交通灯和滨水护栏。
6. 桥梁属于实际跨水的路网边，桥面/引道/护栏共用路径与高程；包括拱桥和高架桥，支持斜向连接。车辆沿相同高程过桥。桥梁按需生成，不固定为三座，无须跨水的地图允许没有桥。
7. 建筑使用真正的 3D GLB 模型，前后侧可观察，有檐口、窗框、阳台或店面等实际几何细节；按体积、朝向、道路和水域约束放置。城区、住宅区、公园形成有组织的空间。
8. 使用模型实例复用与静态几何合批，避免每个窗户和树叶产生独立绘制调用。
9. 行人走人行道，汽车走车道，按距离连续运动，在路口换边；暂停同时停止时间和运动。
10. 晴/雨/雪；可调整一天中的时间；昼夜影响照明、天空、窗光和路灯，雨雪有动态效果。
11. 随机种子输入、建筑密度、天气、时间、暂停、旋转/平移、复位、导出截图；移动端控件不挡住主要城市。
12. 加载与 WebGL 错误可见；重复生成释放旧场景资源；不请求旧静态地图或建筑 sprite。

## 验证

- 多种子测试：路网连通；桥端在陆地；非桥路段不入水；建筑地块不相交、不压路、不入水；人车轨迹符合道路高程。
- 多样性测试：对比水陆掩码、海岸方向、山峰数量与所在象限、桥梁数量、公园位置及路网节点数量；输出六个种子的真实俯视截图。
- 桌面/手机截图检查构图、真实模型加载、地形/桥路衔接与界面遮挡。
- 自动交互验证旋转、平移、缩放、复位、重生成、昼夜、天气、暂停；检查 canvas 像素与运行时错误。
- 构建和 lint 通过；性能记录为实测数据，不提前承诺帧率。

## 素材

Kenney City Kit Suburban 2.0 / Commercial 2.1、Car Kit、Nature Kit，CC0。原始许可随模型保留。之前生成的插画素材保留在磁盘，但不进入新渲染管线。参考图片是观感目标，不能用一张效果图充当城市。
